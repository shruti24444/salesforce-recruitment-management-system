# Salesforce Recruitment Management System

This project is a Salesforce-based Recruitment Management System built using custom objects, flows, and automation.

## Features
• Candidate Management
• Job Application Tracking
• Interview Scheduling
• Interview Result Automation
• Automatic Email Notification for Selected Candidates
• Dashboard for Recruitment Insights

## Technologies Used
• Salesforce Platform
• Flow Builder
• Custom Objects
• Automation
• Reports & Dashboards

## Objects Created
1. Candidate
2. Job Position
3. Application
4. Interview

## Automation
When Interview Result = Pass:
• Candidate Application Status is updated
• Automated email notification is sent to the candidate

## Project Purpose
This project demonstrates Salesforce automation using record-triggered flows for recruitment workflow management.
